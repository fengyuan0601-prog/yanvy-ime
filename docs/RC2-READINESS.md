# 0.1.0-rc.2：正式发布前复查

2026-10-26，接续维护者的发布前检查请求。结论：发现并修复了输入编辑顺序、安装失败处理和候选窗边界问题，交付 rc.2 供最终实机验收；目前不能据此宣布正式稳定版。名称、图标、既定路线和五种输入方案保持连续。

## 复现与修复

1. **延迟编辑可能覆盖较新的输入。** TSF 同步编辑会先于已经排队的异步编辑执行。旧逻辑中，一次预编辑排队后，后续提交可能先同步执行，再被旧预编辑覆盖。合成 ITfContext 按 Microsoft 文档中的调度规则复现失败。现在同一服务已有待处理编辑时，后续编辑、取消清理和定位均保持排队；每个提交仍按顺序执行，已执行失败的回调不会重复执行。较旧文档回调也不再把最新引擎快照和候选 UI 回退。
2. **注销被拒仍继续删除依赖。** 原逻辑在 TSF 注销失败时继续删除 COM 注册和启动项。现在不预先禁用现有方案，每一步失败即停止后续清理并返回错误；支持部分完成后的重试。
3. **回退失败仍清理新版本。** 真实 NSIS 脚本搭配隔离回调复现：旧版本恢复失败仍返回普通失败码 30 并删除新文件。现在只有恢复成功后才更新旧版本元数据；无法恢复返回 31，并保留新旧文件。界面区分安装回退、卸载被拒与回退未完成。
4. **候选窗超出屏幕及无候选时重叠。** 原生绘制复现：32 号字、10 候选时，96 DPI 已需 588 像素，超过 480 像素可用高度。现在按显示器可用区域约束整体绘制比例，保留整页候选和点击位置，不改保存的字号；有编码但无候选时独立显示提示。
5. **测试启动等待过短。** 全新隔离 profile 首次编译词库时，管道测试早于服务就绪而失败。测试现单独给予启动最多 30 秒，普通请求仍保持原短超时；未放宽候选或隐私断言。实际安装过程先运行词库校验和部署。

## 正式版关口

本次只读核对发现，机器仍运行 dev.1 引擎，系统卸载入口记录 dev.2；此前真实试用反馈不能证明本次 rc.2 已实装通过。

1. 用本次安装包完成真实管理员升级，保存工作后重开应用，确认新版本输入法可用；再验证当前版本卸载与重新安装。Windows UAC 由维护者本人处理，自动检查没有替代系统授权。
2. 用合成文本在记事本、浏览器、聊天草稿、Word/WPS 中验证全拼和所需双拼，尤其检查连续输入、数字选词、Esc、失焦、快捷键、候选点击；补齐多屏、高 DPI、休眠恢复及最终构建的 Windows 文件/网络观察。

验收记录应注明系统/应用版本、输入方案、步骤、预期和实际结果；不要记录密码或私密正文。目前仅面向 Windows 10/11 x64 的 64 位桌面应用测试。当前只有 x64 TSF DLL，暂不支持 32 位宿主（含 32 位 Office/WPS），需要补充 x86 前端；ARM64、UWP 未验收，没有手机包。安装包未签名，未创建稳定版标签或正式 Release。
