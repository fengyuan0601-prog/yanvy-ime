# 0.1.0-rc.6：受保护安装目录与升级清理

维护者反馈 rc.5 在 `C:\Program Files (x86)` 安装时，普通用户写入检查提前阻止了安装，并要求新版能选择其他位置、自动移除旧版。

## 修改

- 安装位置支持直接编辑完整本地路径，也可浏览选择；空目录直接使用，非空目录自动建议言舟版本子目录，避免覆盖已有文件。程序文件由正常 UAC 管理员安装，不再要求普通用户能写入程序目录。网络路径、重解析点及非空目标仍拒绝覆盖。
- 设置与词库缓存由当前用户单独保存，程序目录只作可信数据源。若 `E:\Codex\Programs` 存在且可写，优先用其下 `YANVY-UserData/用户 SID`；否则使用当前用户 LocalAppData/YANVY（Windows 常见默认在系统盘）。无学习补丁只从安装包按固定文件名复制，已有文件不覆盖，核心仍校验固定哈希和有效配置，异常时拒绝启动。安装器保存的默认方案和旧版合法选项会提供初始值，安装结束由普通用户应用所选方案。
- 升级先部署、验证并注册新版，再验证系统记录中旧版位置和标记，只删除清单内的旧版程序、词库及已知编译缓存；不运行旧版卸载器，不递归删除目录。旧设置和未知文件保留；被占用文件安排重启后清理。如果旧路径或标记无法验证，保留旧目录并告知用户。已有用户本地设置和缓存保留。
- 新进程使用 v4 管道名称，避免与正在运行的旧版引擎互连；原有线协议未改变。

## 已验证与限制

- 16 项本地安装路径边界通过，包含 Program Files (x86) 形式；无 E 盘回退为合成路径测试。
- 在 E 盘独立夹具上设置 ACL，禁止普通用户写入模拟程序目录；真实引擎仍从该目录读取，并向独立用户目录复制可信补丁和生成缓存，35 项输入及隐私检查通过。独立设置目录保存方案通过。
- 已有用户补丁被改动时拒绝启动，不覆盖原文件、不创建用户数据库。
- 8 项真实 NSIS 脚本配替身注册的隔离事务通过，包括新安装失败保留旧版、成功清理旧版程序并保留未知文件和设置、旧标记缺失时保留旧版。测试不会注册实际 TSF。
- 另用真实 librime 和真实 NSIS 脚本，以隔离注册替身验证正常安装、旧版清理与设置保留、篡改词库拒绝、缺失引擎 DLL 等 4 个场景。测试路径包含中文和空格。
- 已安装版本的真实管理员升级、重启后的占用文件清理、在 Program Files 的实际安装与目标应用输入仍需维护者验证。旧目录中历史用户设置或未知文件可能留存，不能说整个目录一定消失。32 位宿主应用仍不支持。本版本是未签名候选版。
