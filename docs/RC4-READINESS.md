# 0.1.0-rc.4：托盘设置与安装位置

2026-10-28，针对维护者反馈：

- 引擎运行时增加独立的言舟通知区域图标，右键菜单提供“言舟设置”和本次运行隐藏图标；双击图标也打开设置。Windows 可能把图标放进任务栏隐藏图标区域，系统的语言指示器仍由 Windows 管理。
- 安装路径可选其他本地磁盘和当前用户可写目录；选择父目录后自动新建 `YANVY/版本号`。当 E:\Codex\Programs 存在时保留本机习惯，否则默认使用当前用户的本地应用目录。无 E 盘时改用系统临时目录，载荷仍放入独立受保护目录。用户选择的安装父目录会先以普通权限检查可写性。
- 新版本引擎使用独立 v3 管道名称，避免升级时连接仍在运行的旧版本；请求结构和协议版本未变。

本机验证：15 项安装目录边界、合成的无 E 盘默认位置和临时目录选择检查通过；7 项真实 NSIS 脚本配替身回调的隔离事务通过，包含含中文及空格的路径；35 项独立 v3 管道和真实核心检查通过；Windows Shell 托盘图标添加和移除的短时检查通过。测试没有替代实际管理员安装、无 E 盘电脑上的实机测试，也没有人工验证右键菜单完整操作。运行中的旧版输入法未被停止。

GitHub Linux/Windows 检查及新包对应的提交与哈希见交付包 BUILD-INFO.json。rc.4 仍为未签名候选版；尚需维护者验证托盘右键、非 E 盘安装、升级与卸载和代表应用输入。32 位宿主应用仍不支持。[rc.3 历史记录](RC3-READINESS.md)。
