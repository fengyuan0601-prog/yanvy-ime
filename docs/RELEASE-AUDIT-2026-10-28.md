# 言舟 0.1.0-rc.9 发布审计（2026-10-28）

结论：**不满足正式版条件**。本次检查覆盖以下范围，不能推断所有 Windows 应用或设备都已兼容。

## 阻止正式发布的问题

- 用户报告升级后，在已打开的 Codex 和其他应用中 Ctrl+空格无法切换；新打开的记事本可以切换到英文。本机检查发现 Codex 进程仍加载 rc.6 的 TSF DLL。rc.9 兼容桥可以转发旧版本的引擎请求，但不能改变旧 DLL 内部的快捷键处理。尚未证明可以安全地、不关闭应用地替换或修复已经加载的 DLL；不能宣称该问题已解决。
- 另一台 Windows 11 机器曾出现 rc.7 安装检查错误 26，根因未确认，也没有该机器使用 rc.9 的完整诊断和复测结果。
- Codex、实际 32 位应用以及真实管理员安装、跨位置升级与卸载尚无完整验收结果。测试夹具不能代替这些实机验证。
- 安装程序未签名，Windows 下的运行时网络行为尚无抓包或系统调用跟踪结果。本次源代码检索和核心隐私回归不能替代完整安全审计。

## 已核对的证据

- Windows 本机真实 librime 核心：65 项通过，1 项网络跟踪跳过；覆盖五笔、全拼、三种双拼、候选提交、无学习和配置篡改检查。此测试不验证 TSF 的真实应用输入。
- 独立命名空间中的真实引擎与通信：53 项通过；旧入口被占用后保留原占用者、释放后接管；32 位测试客户端可连接真实引擎。未触碰正在使用的输入法服务。
- 隔离安装夹具使用真实 librime 验证了安装、升级、数据被修改及引擎 DLL 缺失四种情况，均符合预期；其中 TSF 注册是模拟的，并非真实系统安装验收。
- 已安装 rc.9 的核心程序、两个架构的 TSF DLL 及抽样词库文件与构建清单哈希一致；安装程序 SHA-256 为 `2a9357a9353b68c9d70140c3156066656274c1fe54ebd051f2264f195ac54c06`。
- 源码提交 `7c2b584822fae27b4e05e2d8d415659d52ebe5ae` 的 [Windows Actions](https://github.com/fengyuan0601-prog/yanvy-ime/actions/runs/40701236412) 与 [Linux Actions](https://github.com/fengyuan0601-prog/yanvy-ime/actions/runs/40701236399) 已成功。它们不证明真实应用矩阵通过。
- 审计时发现核心测试脚本在非 UTF-8 Windows 默认编码下读取中文配置会失败；已为测试中的文本读写显式指定 UTF-8，并在关闭 Python UTF-8 模式后重跑通过。该修改只影响测试工具，不修复产品快捷键。

已打开应用的旧组件问题需要继续探索受支持、不会丢失输入的更新机制，并在真实应用中验证。不要通过强制关闭用户应用、注入其他进程或禁用隐私校验来绕过问题。
