# 0.1.0-rc.1：安装器与输入方案

2026-10-26，接续维护者的三个反馈：安装器界面需要重做；五笔/拼音入口不清楚；拼音应支持全拼和多种双拼，可参考搜狗的分类方式。名称与路线延续原工程。

## 本次实现

- 原生安装/卸载界面统一品牌与排版，包含安装位置、可见的默认方案、真实任务等待、完成与失败页面。主界面以普通权限打开，点击安装/卸载才请求正常 UAC。后台载荷只在 E 盘新的受保护临时目录提取，完成后清理；没有运行期下载。
- 设置改为“输入方案 / 外观 / 关于”。拼音先选全拼或双拼，双拼列出小鹤、自然码、微软；保留五笔86。当前选择和示例明确显示，不要求记快捷键。
- 候选窗的方案名带有 ▾，点击可直接打开设置。保存后下次输入应用方案，取消未确认编码；快捷键仍可在五笔与所选拼音间切换。
- 双拼来自固定提交的 Rime GPL-3.0 原方案，使用已有简体拼音词典，保留键位与预编辑格式，独立补丁固定无学习。原始文件、许可和哈希保留，不复制搜狗的代码、素材或词库。
- 扩展核心允许清单与有效配置检查；所有新方案均在创建会话前检查。没有通过放开任意配置、脚本或用户词库来实现双拼。
- 新协议/管道名使用 v2，避免新旧引擎在升级后误连。旧版正在使用的进程没有被本轮测试停止或替换。
- 修复安装在词库校验失败、尚未尝试注册时也会注销旧版本的问题；注册后失败会尝试恢复之前版本。卸载等待实际清理完成才显示结果。文件删除继续采用明确清单，保留未知文件和设置。
- 设置采用临时文件加替换方式保存，防止只写入部分选项；保留未知键，分别记住拼音与双拼选择。

## 已运行检查

本机 Windows 11 x64（系统 10.0.26340）、既有 E 盘 GCC 16.2.0/CMake 4.4.3/NSIS、固定官方 librime 1.10.0。

| 检查 | 实际结果与范围 |
| --- | --- |
| 真实核心及隐私反例 | 65 PASS、1 SKIP；包含三种双拼候选、提交、取消和各方案源补丁/编译缓存学习绕过反例；Windows 网络追踪跳过 |
| 原生管道与引擎 | 35 PASS；五笔、全拼、三种双拼、焦点所有者隔离和无 userdb/正文标记落盘；在独立 v2 端点运行 |
| COM ABI | `--com-smoke` 为 `0x0`，不代表系统应用完整验收 |
| 安装目录边界 | 15 项通过，拒绝系统盘、UNC、路径跳转、控制字符等 |
| NSIS 事务夹具 | 词库校验失败不碰旧注册、注册失败回退、成功及精确卸载保留设置/未知文件通过；使用替身回调与独立 HKCU 键，未调用真实 TSF 注册 |
| 原生配置夹具 | 原子保存/重读、未知键保留、失败保留旧配置、非法值回退、五笔与拼音选择分别记忆通过；写入独立临时目录 |
| 原生界面 | 实际显示并检查安装器、版本说明和新设置页；多个 DPI/状态的绘制检查和 GitHub 构建结果以本次实际运行记录为准 |

本轮独立设置预览中断于用户切换窗口，未继续抢占焦点；不将配置夹具当作完整的人工 UI 点击矩阵。

## 正式版仍需完成

当前只交付候选版，不把自动检查通过等同于正式版验收。仍需本次真实安装器的管理员升级/卸载、常用原生应用/浏览器/聊天与 Office/WPS 中全拼和双拼输入、失焦/快捷键/多屏/休眠，以及最终发布构建的 Windows 文件与网络观察。此前维护者的真实试用反馈保留，但不能替代这些未运行项目。

安装操作需要维护者在系统 UAC 中完成授权；本轮没有自动改动当前输入法注册。没有手机安装包。
