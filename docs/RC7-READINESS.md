# 0.1.0-rc.7：通知区设置入口

- 言舟自身仍只创建一个通知区图标；右键打开菜单，单击打开设置。Windows 控制自己的输入指示器，不能保证它提供相同的右键菜单。
- 图标采用 Shell 的版本 4 通知回调，版本设置失败时回退旧式消息；提供标准提示文本，并支持键盘选中操作。Explorer 重启后重新注册。
- 安装成功后，新版安装程序通过本版可信的安装助手通知当前用户会话中的旧版 v3/v4 引擎退出，以减少升级后旧图标残留；保留用户数据。
- 图标添加、版本设置和删除可自动验证，实际托盘鼠标菜单、Windows 输入指示器的具体行为、完整升级及多应用输入仍须在目标电脑人工验证。该候选版未经签名，不是正式稳定版。
