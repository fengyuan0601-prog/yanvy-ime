# 言舟 · YANVY 品牌与图标说明

日期：2026-10-26｜本文件描述当前品牌方向，不等同于商标核准。

## 名称使用

| 场景 | 写法 |
| --- | --- |
| 中文产品名 | 言舟输入法 |
| 中英并列 | 言舟 · YANVY |
| 英文产品名 | YANVY Input |
| 英文建议读音 | YAN-vee，两音节 |
| 开发者/所属品牌 | 一念开物 · IDEORIN |

英文是产品识别名，不给它编造外语词源。中文“言”对应表达，“舟”表达平稳承载文字的意象。品牌语气安静、直接、可靠；产品页面先解释怎样输入、支持什么和如何保护隐私。

IDEORIN 出现在关于页、项目版权/维护信息和官网产品归属中。键盘与候选窗主要呈现当前输入状态，不常驻整段品牌文案。

## 图标方向

采用“文字之舟”的抽象结构：舟形轮廓与少量文字笔画结合，V形关系呼应英文名称。以深青蓝、温白和少量青碧形成稳定识别，避免完整文字挤入小图标。

首版视觉要求：

- 轮廓简洁，在小尺寸仍可辨认；单色版也能表达主要结构。
- 保持舟形平稳，不通过飞行拖尾或纸飞机形状暗示上传消息。
- 不增加盾牌、挂锁、眼睛、键盘阵列等额外符号堆叠。
- 深浅背景都需检查透明边缘；不要用过强阴影或高光替代清楚的形体。
- 主图标用于应用与安装入口，输入模式使用单独清楚的“中/英”“五/拼”状态标识。

参考色板如下，属于后续界面配色建议，**不是对 PNG 像素的测量结果**：

## 界面延展

Windows 候选窗采用紧凑排版、清楚的选中态和适度圆角；不为展示品牌增加占屏面积。设置页按“输入”“外观”“隐私与数据”“关于”组织，说明当前哪些功能只在本机运行。手机键盘优先按键大小、触达、候选可读性和删除行为；配色与 PC 呼应，布局服从手机使用。

Windows 托盘/输入指示器图标需要作为可执行文件或 DLL 的资源接入，并实测缩放效果；不能认为提供一个独立 PNG 就完成系统接入。依据：[Microsoft IME 图标要求](https://learn.microsoft.com/en-us/windows/apps/develop/input/input-method-editor-requirements)。

## 可使用的产品介绍

> 言舟是一款免费开源的五笔、拼音输入法，专注本地输入。官方版本不加入广告，不上传输入内容。由独立开发者持续维护。

这段介绍是**产品目标文案**，正式发布时须与已验证版本的实际行为一致。当前阶段对外进度说明应同时写明“Linux本地输入核心已完成开发验证，Windows与手机系统接入尚未验收”，不能让品牌文案代替工程状态。
