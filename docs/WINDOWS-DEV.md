## 已实现与构建

- 真实 Windows x64 核心：固定 librime 1.10.0 官方 clang SDK，通过 C ABI 连接现有适配器。保留原词库、哈希清单、无学习配置和有效组件检查。
- 原生 TSF DLL：键盘事件、组合范围/提交/取消、选择位置、焦点与文本布局 sink。参考并适配固定 Weasel 0.17.4，衍生源文件使用 GPL-3.0-or-later。
- Win32/GDI 候选窗：候选显示、点击选词、深浅色和字号设置；不激活候选窗，不使用剪贴板或模拟粘贴。
- 单一真实引擎进程：按 Windows 用户和登录会话命名的本地管道；只允许本用户/SYSTEM、拒绝远程连接，消息和 IO 有长度/超时限制。焦点所有者改变会清空旧组合，旧所有者的失焦清理不影响新所有者。
- 引擎继续按进程初始化一次，没有为每个 TSF 输入框构建并行 `Engine`。原生输入过程没有诊断正文输出。
- NSIS 安装/卸载：默认 E 盘、正常 UAC、固定数据校验、注册失败回退、精确列举文件移除、保护未知文件及其他输入法。当前版本不静默覆盖已有目录；升级矩阵尚待后续实测。

这些是**源码实现及构建事实**；可观察的系统输入行为仍需在全局注册后验证。

### 发现并修复的问题

Windows 维护流程会重建被修改的编译缓存，原“缓存篡改应拒绝”检查因此在最初运行失败。现已在已有缓存时增加维护前有效配置检查，维护后/创建会话前检查仍保留。反例回归通过，没有更改预期来放行。

Windows 中文路径原来经过窄字符参数/本地编码，现通过 `wmain`、宽字符模块路径及 `u8path/u8string` 处理。保护目录拒绝 Windows reparse point；没有关闭受信检查。
