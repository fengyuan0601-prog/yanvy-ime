# 0.1.0-rc.8：中英文切换状态同步

维护者反馈 Ctrl+空格切到英文后，言舟仍处于选中状态，但无法切回中文。此前言舟只维护本地中英文状态，没有监听 Windows TSF 的输入法开关，存在状态不同步的风险；具体用户环境中的事件顺序尚未确认。

- 监听当前 TSF 线程的键盘开关，Windows 更改该状态时同步言舟的中英文状态；言舟处理快捷键时也同步写入系统状态。切换时取消未确认的组合串。
- 偏好刷新不再静默把中文模式重置为开启状态，以免与系统状态分离。升级时通知 v3、v4 和 v5 旧版引擎退出；继续只创建一个言舟通知图标。
- 使用私有的真实 TSF 线程管理器和 compartment 测试多次关开及外部状态变化，不改动系统输入法注册，不模拟真实按键。目标应用中的 Ctrl+空格和安装升级仍需维护者实机验收；不能据此宣称已发布正式稳定版。

另一台 Windows 11 设备报告 rc.7 词库检查异常退出（26）。该类别原先丢弃子进程的具体异常码；rc.8 在完成安全回退后显示 Windows 异常码，不记录输入或路径。此改动用于定位原因，不代表该设备的安装问题已修复。
