# 0.1.0-rc.3：候选窗定位复查

2026-10-28 检查时，本机安装入口和运行中的引擎均为 rc.2。按 rc.2 交付记录对已安装程序、词库和许可文件做只读 SHA-256 比对，65 项一致；未触碰正在运行的引擎或输入内容。

代码复查发现：切换输入上下文后，或者应用不能返回文字位置时，旧实现可能保留上一个输入框的候选窗坐标。rc.3 在上下文切换和重新查询前清除旧坐标；位置查询失败、区域被裁剪或返回空矩形时，使用当前线程的系统光标位置作为原有后备，若不可用则隐藏候选窗。合成几何检查覆盖失败、裁剪、有效和空位置，候选绘制的 48 组边界检查继续运行。这是代码路径与隔离检查，不代表已经在所有应用、多屏和高 DPI 实机验证。

本机重新运行 rc.2 核心：65 PASS、1 SKIP（Windows 未执行 Linux strace 网络追踪）；18 项编辑会话、注册清理、48 组候选布局及 COM ABI 隔离检查通过。具体历史和检查边界见 [rc.2 记录](RC2-READINESS.md)。GitHub CI 与新包的提交和哈希见本次交付的 BUILD-INFO.json。

rc.3 尚待维护者完成实际升级及代表应用输入、焦点切换、多屏、休眠和卸载验收；此前 rc.2 已安装不代表 rc.3 已安装。当前只支持 x64 宿主测试，不支持 32 位应用；ARM64、UWP 与移动端不在已验证范围。安装包未签名，仍是候选版。
