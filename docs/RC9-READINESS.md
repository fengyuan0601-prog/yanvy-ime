# 0.1.0-rc.9：跨应用升级兼容与 32 位组件

维护者报告 Codex 中无法输入。检查发现它仍加载 rc.6 的 TSF DLL，而升级已停止其 v4 引擎；注册新版后，已运行程序不会立即卸载旧 DLL。

- 新引擎提供与协议 2 兼容的 v2–v6 本地通信入口，转发到同一个当前引擎；旧引擎仍占用的入口不会被抢占，退出后自动接管。所有入口保留当前用户/会话的访问限制，且不记录输入内容。
- 安装成功后从普通用户界面启动新版引擎，帮助已运行应用继续输入。旧组件自身的旧行为仍可能存在，不能通过服务端兼容改变已加载的 DLL。
- Windows x64 系统同时安装和注册 32 位与 64 位 TSF DLL，安装前用 32 位进程检查组件加载；卸载清理两种 COM 视图。真实的 32 位应用、Codex、其他软件和实际安装升级仍须实测。
- 旧版兼容与双架构夹具不等于所有应用已兼容；ARM64、UWP、安全桌面、完整应用矩阵及另一台电脑报告的安装错误 26 仍未解决或验收。未签名候选版，不是正式稳定版。
