# 言舟 · YANVY 命名记录

日期：2026-10-26｜范围：公开网络同名初筛，不是商标审查。

## 当前工作命名

采用 **言舟 · YANVY**，中文完整名称“言舟输入法”，英文“YANVY Input”，英文读音建议为 YAN-vee。

“言舟”与朝暮、时境、映和的两字命名风格接近，体现文字表达与平稳承载，不限定五笔、拼音或某一种设备。YANVY 为本项目选择的英文识别名，不宣称具有固定词源或全球独占权。
