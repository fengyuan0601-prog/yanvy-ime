# Windows UI 接续：0.1.0-dev.2

2026-10-26，接续已有 TSF 与 librime。维护者报告正在用 dev.1 输入，整体良好，希望优化 UI；该反馈未包含完整应用版本和操作矩阵。本次版本仍为未签名开发测试包。

## 可观察的改动

- 原生候选窗改为紧凑的自适应宽度、圆角与浅色/深色，编码、选中项、序号和当前方案各有清楚层次；保留点击选词、无激活、翻页与跟随文本位置。
- 候选窗口按 DPI 重排并限制在显示器工作区内，底部空间不足时放在输入位置上方；实际多屏位置行为尚待验证。
- 原生设置页按 DPI 缩放，提供 12–32 候选字号、跟随系统/浅色/深色、即时外观预览、恢复默认和行内保存状态。预览明确标记为示例文字，使用同一个候选绘制器。
- 升级安装到新版本目录，仅迁移范围内的字号/配色；保留旧目录。新版卸载入口检查当前注册目录，避免注销其他版本。dev.1 的旧卸载程序没有这一保护，请使用 Windows 已安装应用中的当前入口。
- 输入键处理、管道协议、核心、词库和默认无学习策略沿用现有实现，没有为外观添加输入日志、遥测或联网功能。

## 本轮 Windows 验证

使用 E 盘既有 UCRT64 GCC 16.2.0、CMake 4.4.3、Windows 系统 GDI/GDI+，官方固定 librime 1.10.0。维护者正在使用的 dev.1 进程与系统注册未改动；新界面在独立构建目录中检查。

| 检查 | 实际范围 |
| --- | --- |
| 原生候选窗 | 使用合成文本在隔离预览中显示；核对实际窗口布局、浅/深色和选中项 |
| 实际绘制器 | 分别以 96/144/192 DPI 输出原生 PNG，检查字形、圆角与布局；不等同于真实多屏 TSF 输入测试 |
| 设置操作 | 实际点击深色、保存，重开后保留；切换到 32 字号未截断；恢复默认并保存后确认为字号 18/跟随系统 |
| 外观迁移 | 将实际 NSIS 迁移函数编译为独立夹具，在 E 盘临时目录验证正常值、上下界、越界、非法值与无安装标记 6 项通过；旧文件及未知键未复制或修改，未更改系统注册 |
| 构建与 COM ABI | 本机全部生产目标与绘制器构建通过，`--com-smoke` 返回 `0x0`；没有启动本地管道测试去打断正在使用的引擎 |
| 系统输入与升级卸载 | dev.2 尚未在用户当前应用中验收；没有自动替换正在使用的 dev.1 |

GitHub Windows 工作流继续运行原核心隐私/编辑回归、COM ABI 与管道隔离，并新增原生绘制器的三个 DPI 构建/渲染。以 Actions 的实际提交结果为准。

## 安装后重点反馈

重开应用或注销再登录后观察新版候选窗；先保存当前工作。检查输入框接近屏幕底部时的位置、常用缩放下的清晰度、选中项与数字是否易读，以及是否仍有吞键/重字/失焦误提交。不要为反馈提交私密正文。

完整的记事本、浏览器、聊天应用、Word/WPS、32 位应用、多屏和安装升级卸载矩阵仍按现有路线继续，未全部验收前不标记稳定版。没有手机安装包。
