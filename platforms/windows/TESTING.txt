言舟 · YANVY 0.1.0-rc.3 — Windows x64 候选版

本版继续优化全拼和三种双拼，并改进切换输入框时的候选窗定位。
此前已有维护者真实输入试用反馈；本版未签名，仍待完整跨应用、
实际管理员升级卸载与多屏验收，目前不标记为正式稳定版。
支持 Windows 10/11 x64 中的 64 位桌面应用测试；仅含 x64 前端，
暂不支持 32 位宿主应用（包括 32 位 Office/WPS）。ARM64、UWP、
安全桌面、64 位聊天/Office/WPS、休眠与高 DPI 矩阵未完成验收。

安装：
1. 运行 YANVY-0.1.0-rc.3-windows-x64-setup.exe，查看安装位置，
   直接选择默认方案：全拼、小鹤双拼、自然码双拼、微软双拼或五笔86。
2. 点击“安装言舟”后，系统注册会请求 Windows 管理员授权。
   程序、词库和本地编译缓存默认位于 E:\Codex\Programs\YANVY\0.1.0-rc.3。
   安装临时文件也使用 E 盘；此包要求有可写的 E 盘。
   系统注册表由 Windows 管理；不强改系统默认输入法。
3. 安装完成后保存工作、重新打开要测试的应用，在系统输入法
   切换器中选择“言舟 · YANVY (开发测试)”。列表未刷新时可注销再登录。
4. TSF 启用时会启动本版本引擎。也可从开始菜单“言舟 YANVY 开发测试”
   启动言舟引擎；首次部署可能需要数秒。新版 v2 引擎不会误连旧进程。

选择输入方式（不需要记快捷键）：
- 开始菜单“言舟 YANVY 开发测试”→“言舟设置”→“输入方案”。
- 先选“拼音 / 五笔86”；拼音再选“全拼 / 双拼”。选择双拼后，
  从下拉框选择“小鹤双拼 / 自然码双拼 / 微软双拼”。
- 点击“保存并应用”，下一次输入生效；当前未确认编码会取消。
- 输入时点击候选窗顶部带 ⇄ 的方案名，可直接在五笔与上次选择的拼音之间切换。
- 要改为全拼或其他双拼方案，打开开始菜单中的“言舟设置”。
- 新安装默认全拼；升级时可在安装界面确认或更改默认方案。

合成示例和基本操作：
- 全拼 nihao；小鹤双拼 nihc；自然码/微软双拼 nihk，均应出现“你好”。
  双拼使用对应的声韵键位，不是全拼与双拼自动混输模式。
- 五笔86输入 wqvb，候选应包含“你好”“您好”。
- 空格：确认候选；数字 1–5：选词；PgUp/PgDn：翻页。
- Backspace：编辑；Esc：取消未完成组合；Enter：提交编码。
- Ctrl+Shift+F12：五笔86 / 已选拼音方案切换，未完成输入取消。
- Ctrl+Space：中/英切换，未完成输入取消；是否与其他程序快捷键冲突需实机验证。
- 候选项可以点击；未确认组合失焦后应取消，不能送入另一窗口。
- “外观”提供即时预览、12–32 字号、跟随系统/浅色/深色及恢复默认。
- 大字号或屏幕可用空间较小时，候选窗按可用空间缩放，保留整页候选；
  不修改保存的字号。无匹配候选时，编码与操作提示分行显示。

从 dev.1/dev.2 升级：
安装到新的版本目录，旧目录保留；仅迁移合法外观与方案选项，
不复制旧引擎 profile、缓存或其他配置。新 DLL 需要重开应用才能加载。
请使用 Windows 已安装应用中的当前卸载入口，不要运行旧 dev.1
目录里的卸载程序，它可能注销当前版本共享的输入法注册。

验证与反馈：
请使用合成文本依次检查记事本、浏览器文本框、Word/WPS、聊天应用
未发送草稿。优先记录吞键、重字、失焦误提交、候选位置偏移和切换失败。
反馈包含应用/系统版本、输入方案、按键步骤、预期与实际结果；
不要提供密码、私密正文或个人词库。

卸载：
先切换其他输入法并关闭使用言舟的应用，从 Windows 已安装应用列表
或当前安装目录的 Uninstall.exe 卸载。只移除言舟注册和列明文件，
保留外观设置及未知文件；不移除其他输入法，不强制关闭其他应用。
被占用的文件可能在重启后删除，不会自动重启。

隐私与许可：
固定离线词库、默认无学习、没有产品联网功能、正文日志或剪贴板历史。
引擎仍会写部署配置与编译缓存，不宣称零写盘；Windows 运行期网络追踪待完成。
