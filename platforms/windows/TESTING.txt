言舟 · YANVY — Windows 使用说明

实际版本号见安装向导、设置页和 BUILD-INFO.json。本包未签名。
适用范围：Windows 11 x64 桌面系统，随包提供 x64 与 x86 TSF 组件。
不同应用的兼容性以发行页的实际验证记录为准；不承诺所有应用均已验收。

安装
1. 从官方发行页获取完整安装包，运行 YANVY-版本号-windows-x64-setup.exe。
   保持普通权限启动；安装系统组件时会由 Windows 请求管理员授权。
   0.1.6 会尝试将意外继承管理员权限的向导交回普通用户桌面重新打开。
   如果系统未提供普通用户桌面（例如关闭 UAC 后的管理员会话），向导会
   在写入文件前说明原因；查看诊断可见进程、桌面权限与 UAC 设置状态。
2. 在“词库位置”中直接输入完整路径，或点击“更改”选择本地目录。
   可以选择其他盘符，不要求有 E 盘。选择非空目录时，向导会尝试使用
   言舟版本子目录；同一安装包的完整词库可直接复用。网络路径和目录链接不用于安装。
3. 选择默认方案：全拼、小鹤双拼、自然码双拼、微软双拼或五笔86。
   新安装默认全拼，升级时也可以在此更改。
4. 点击“开始安装”。向导先准备词库，再请求管理员授权安装系统组件。
   程序与 DLL 固定存放于 Windows 的 64 位 Program Files\YANVY\版本号，
   通常在 C 盘。这是为保护系统输入法组件，避免从普通用户可改写的目录
   加载程序；所选词库位置仍保持不变。系统注册表由 Windows 管理。
5. 安装完成后，在 Windows 输入法列表中选择“言舟 · YANVY”。
   言舟不会更改系统默认输入法，也不会自动关闭其他应用或重启电脑。
   引擎按需启动，首次准备可能需要数秒。

设置与存储
- 任务栏保留 Windows 的言舟品牌图标，并提供“中/英”模式按钮。
  左键“中/英”切换输入模式，右键直接打开言舟设置。
  品牌图标用于 Windows 输入法选择；引擎不再创建额外的独立托盘图标。
- 也可从开始菜单“言舟 YANVY”打开设置。系统是否显示模式按钮取决于
  当前桌面宿主；特定应用的实际验证范围见发行记录。
- 个人设置和引擎缓存与系统程序分开保存。E:\Codex\Programs 存在且
  可写时，使用其下 YANVY-UserData\用户 SID；否则使用当前用户的
  LocalAppData\YANVY。无 E 盘时也可正常使用。
- 词库位置保存离线数据。系统组件中保留固定数据备份，供无法访问
  安装用户词库位置的其他 Windows 账户使用。

选择输入方案
- 打开设置中的“输入方式”，直接选择全拼、五笔86、小鹤双拼、自然码双拼或微软双拼卡片。
- 每张卡片展示用途和“你好”的输入示例，选中的方案会显示勾选标记。
- 点击“保存并应用”，下一次输入生效，当前未确认编码会取消。
- 点击候选窗顶部带 ⇄ 的方案名，可在五笔与上次选择的拼音之间切换。
- “外观与显示”可实时预览字号与配色，支持 12–32 字号、跟随系统、浅色“云白”、深色“夜航”和恢复默认。
- 设置窗口中可用 Ctrl+1/2/3 切换页面，Ctrl+S 保存；Tab 移动焦点、空格选择按钮。

输入与快捷键
- 全拼 nihao；小鹤双拼 nihc；自然码或微软双拼 nihk，均可输入“你好”。
  双拼使用所选方案的声母、韵母键位，不是全拼与双拼自动混输。
- 五笔86输入 wqvb，可选择“你好”“您好”等候选。
- Ctrl+空格：中文 / 英文切换，未完成输入取消。
- Ctrl+Shift+F12：五笔86 / 已选拼音方案切换，未完成输入取消。
- 空格确认候选；数字 1–5 选词；PgUp/PgDn 翻页；也可直接点击候选。
- Backspace 编辑；Esc 取消未完成组合；Enter 提交编码。
- 未确认组合在失焦后取消，避免送入其他窗口。

升级
直接运行新版安装包，可以重新选择词库目录，不必提前卸载旧版本。
安装器先准备并注册新版，成功后处理系统记录中的旧版。恢复与清理均
使用新版自身的工具，不运行旧目录中的卸载器或 helper。
保留个人设置和未知文件，不复制旧引擎的 profile 或缓存。
旧文件被应用占用、不可写或无法安全识别时会保留，并在向导中提示；
允许安全安排的文件会在以后重启时清理，安装器不会自动重启。
新版使用独立的系统组件标识，已打开应用的实际切换情况见发行验证记录。
仍驻留的已知旧系统组件可通过兼容设置入口转到当前版本；补回的入口仅在
受保护的已知旧版本目录内创建，并安排在以后正常重启时清理。

重复安装与注册修复
再次运行同一个完整安装包，可复用已有程序和词库，修复输入法注册及启用状态，
也可选择新的空词库位置。复用前按安装包内置清单核验固定文件，保留个人设置和
未知文件；取消管理员授权或修复失败不会删除原有词库和程序。
文件缺失、内容损坏、来自不同安装包或路径不安全时会停止并保留现场。
此功能修复注册与启用，不强行覆盖正在使用或完整性不符的程序文件。

卸载
从 Windows“已安装的应用”选择言舟，或运行当前版本的 Uninstall.exe。
向导会请求管理员授权移除系统输入法注册和列明的系统文件，再由原用户
清理可识别的旧程序与词库文件。个人设置、个人缓存和未知文件保留；
不移除其他输入法，不强制关闭应用。占用或无权清理的文件会保留并提示。

遇到问题
- 安装失败时点击“查看诊断”，记录完整错误代码、Windows 版本和出错阶段。
  诊断没有输入内容、用户名、安装路径或内存转储，不会自动上传。
- 输入问题请记录应用名称与版本、输入方案、按键步骤、预期和实际结果。
  可用“你好”“abc”等合成文字复现，无需提供聊天正文、密码或个人词库。
- 若仅某个应用出问题，请同时说明其他应用的结果，便于定位宿主差异。
- 旧 rc.7 的错误 26 没有保留具体退出状态；不能凭该数字判断是 CPU、
  系统组件还是安全软件。新版本显示更具体的数值诊断，反馈时请保留完整代码。

没有产品联网功能、广告、遥测、正文日志、剪贴板历史或运行期下载。
引擎会写部署配置和编译缓存，不代表零写盘；运行期网络观察的具体覆盖范围
见发行验证记录，不把源码检查当作所有运行场景的网络跟踪证明。
