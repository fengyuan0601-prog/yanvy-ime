言舟 · YANVY 0.1.0-dev.2 — Windows x64 开发测试版

这是 Windows 原生 TSF 外观更新测试包，未签名，不是稳定日用版。
dev.1 已收到维护者真实输入的试用反馈；dev.2 仍待跨应用验收。
只支持 Windows 10/11 x64 中的 64 位桌面应用；32 位、ARM64、UWP、
安全桌面、微信、Office/WPS、休眠与高 DPI 兼容性尚未完成验收。
不要用本测试版输入密码、私密聊天或重要且没有备份的正文。

安装：
1. 运行 YANVY-0.1.0-dev.2-windows-x64-setup.exe。
2. TSF 系统注册需要 Windows 管理员授权，会显示正常 UAC 请求。
   程序、固定词库和本地编译缓存默认放在 E:\Codex\Programs\YANVY\0.1.0-dev.2。
   系统注册表与系统输入法设置由 Windows 管理；不强改默认输入法。
3. 安装完成后从开始菜单“言舟 YANVY 开发测试”启动言舟引擎，
   重开要测试的应用。通过 Windows 输入法切换器选择
   “言舟 · YANVY (开发测试)”。若列表没有刷新，可注销后重新登录。
4. 第一次部署或后台引擎不可用时，按键可能直接交回应用；等待数秒后重试。

基本操作：
- 初始为五笔86：输入 wqvb，候选应包含“你好”“您好”。
- 空格：确认首候选；数字 1–5：选词；PgUp/PgDn：翻页。
- Backspace：编辑；Esc：取消未完成组合；Enter：提交编码。
- Ctrl+Shift+F12：五笔86 / 拼音切换，未完成输入取消。
- 拼音：输入 nihao，空格应提交“你好”；zhongguo 应出现“中国”。
- Ctrl+Space：中/英切换，未完成输入取消。
- 候选项可点击。关闭或切换输入焦点时，未确认组合应被取消，不能送入另一窗口。
- 设置入口在开始菜单“言舟 YANVY 开发测试”下。设置只允许字号和配色。
- 新设置页提供即时预览、12–32 字号、跟随系统/浅色/深色和恢复默认；
  点击“保存更改”后，下次显示候选窗时生效。

从 dev.1 升级：
安装到默认的新版本目录；旧目录保留，仅迁移合法字号与配色，
不复制旧引擎 profile 或缓存。先保存工作，安装后重新打开应用，
必要时注销后重新登录，才能完整加载新版 DLL 与引擎。
请使用 Windows 已安装应用中的当前卸载入口，不要运行旧 dev.1
文件夹里的卸载程序，它可能注销当前版本共享的输入法注册。

请依次使用合成文本测试：
记事本 → 浏览器文本框 → Word/WPS → 聊天应用的未发送草稿。
优先报告：吞键、重字、失焦误提交、窗口串字、候选位置偏移和切换失败。
报告只写应用版本、系统版本、按键步骤、预期与实际结果；请勿附私密正文。

卸载：
先切换到其他输入法并关闭正在使用言舟的应用，再从 Windows 的已安装应用
列表或安装目录的 Uninstall.exe 卸载。卸载只移除言舟的注册和已列明文件；
不会删除或重设其他输入法，不会强制关闭其他应用。被占用的 DLL 可能要重启后删除。

隐私与许可：
固定离线词库、默认无学习、没有产品联网功能、没有正文日志、没有剪贴板历史。
引擎仍会写部署配置与编译缓存；不宣称零写盘。Windows 平台运行期网络追踪未完成。
