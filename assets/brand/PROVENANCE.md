# 图标来源与导出

工作名称：言舟 · YANVY。生成日期：2026-10-26。

本轮使用内置图像生成能力设计原始图标，并以原图为参考生成全幅不透明移动端母版。没有使用第三方品牌图标作为参考，也没有将手绘 SVG 包装成自动矢量化结果。

## 母版

- `yanvy-icon-master-transparent.png`：圆角墨蓝底、温白抽象文字之舟、青碧光标；外围透明，适用于桌面图标与标志展示。
- `yanvy-icon-master-opaque.png`：保持同一图形方向，背景延伸到完整正方形，用于移动端系统裁切适配。

这两张为生成的位图母版，**当前不包含真实 SVG/AI 矢量源文件**。全幅版本来自一次图像编辑，需在正式平台打包时检查安全区与掩模。

## 确定尺寸导出

`export.sh` 使用 ImageMagick 只做标准尺寸缩放和格式编码，不重新设计图形。

- PNG：16、24、32、48、64、128、256、512、1024 像素。
- `yanvy.ico`：16/24/32/48/64/128/256 多尺寸 Windows 容器。
- `yanvy-mobile-1024.png`：1024×1024 不透明移动端母版。

Android adaptive icon 的原生前景/背景图层和 iOS 资产目录将在各自平台工程中继续配置；本批不把一张 PNG 称为已经完成所有商店图标适配。

## 生成提示摘要

单一高质量应用图标；隐私优先的五笔拼音输入法；抽象舟形与横向文字笔画结合，一处青碧输入光标；墨蓝与深青背景、温白标志；小尺寸可辨识；不出现完整名称、文字、键盘、盾牌、挂锁或纸飞机；正面、干净、克制的几何风格。第二次编辑仅将透明圆角外围改为完整不透明方形背景，保留原有标志方向。
